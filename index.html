How a MapReduce job runs

Output lands in part-r-00000 plus an empty _SUCCESS file.
  • Mapper input with TextInputFormat: key = byte offset (LongWritable), value = the line (Text).
  • Combiner allowed when the operation is associative and commutative, and input and output types equal the map output types. It may run zero or many times.
  • Partitioner decides the reducer: default is hash(key) mod number of reducers.
  • Writable is Hadoop's compact serialization; keys must also be comparable so they can be sorted.
  • Output directory must not exist, so a finished result is never overwritten.
  • Data locality: YARN runs a map task on the node holding its block; code moves to the data.

Pig in six lines

  • LOAD … USING PigStorage(',') reads a file; with no schema, fields are $0, $1, …
  • FILTER … BY keeps rows · FOREACH … GENERATE picks and casts columns
  • GROUP … ALL = one group (global) · GROUP … BY x = one group per value
  • ORDER … DESC, LIMIT n, FLATTEN(bag) un-nests a bag back into rows
  • Lazy: nothing runs until STORE (to HDFS) or DUMP (to screen)
  • Modes: pig -x local (local files, one JVM) · pig -x mapreduce (HDFS + YARN, what we used)
MapReduce vs Pig, one lineSame engine underneath. MapReduce gives control (combiner, custom Writable, number of reducers). Pig is faster to write: a grouped top-N is one word (ALL becomes BY x) instead of a secondary-sort job.

VivaShort answers

What is Hadoop?hadoop
An open-source framework for storing and processing very large datasets on clusters of ordinary machines: HDFS for storage, YARN for resources, MapReduce as the processing model.
What is HDFS and how does it store a file?hadoop
The distributed file system. A file is split into blocks (128 MB by default), each block stored on DataNodes and replicated. Our 785.5 MB CSV is 7 blocks with replication 1.
What does the NameNode hold?hadoop
Metadata only: the directory tree, the file-to-block mapping and block locations. The data itself lives on DataNodes.
Is the SecondaryNameNode a backup?hadoop
No. It merges the edit log into the fsimage (checkpointing) so restarts are fast and the log stays small.
What is YARN and why is it needed?hadoop
The resource manager and scheduler. Without it, MapReduce would have to schedule the cluster itself, and only MapReduce could use it. YARN lets many frameworks share one cluster.
Name the YARN components.hadoop
ResourceManager (one per cluster), NodeManager (one per node), a per-job ApplicationMaster, and containers where tasks run.
What is replication and why is yours 1?hadoop
The number of copies of each block, normally 3 for fault tolerance. We have one DataNode, so only one copy is possible.
What is safe mode?hadoop
A read-only state at NameNode start-up while DataNodes report their blocks. Writes and jobs fail until it clears.
Why does a single-machine Hadoop need SSH?hadoop
The start scripts launch each daemon over SSH, even to localhost.
Which six daemons should jps show?hadoop
NameNode, DataNode, SecondaryNameNode, ResourceManager, NodeManager, JobHistoryServer.
Which config file holds what?hadoop
core-site: fs.defaultFS. hdfs-site: replication and the NameNode/DataNode directories. mapred-site: mapreduce.framework.name = yarn. yarn-site: aux-services = mapreduce_shuffle.
Explain MapReduce.mapreduce
Map processes each record independently and emits key-value pairs; the shuffle groups them by key; reduce processes each key's values into the result.
What is the shuffle?mapreduce
Copying map output to the reducers, partitioning by key, sorting and grouping. It crosses the network, so it is the expensive phase.
What is a combiner and when is it legal?mapreduce
A mini reducer on map output before the shuffle. The operation must be associative and commutative, and its input and output types must equal the map output types.
Why must the output directory not exist?mapreduce
Hadoop refuses to overwrite it, which protects earlier results.
What files does a job write?mapreduce
part-r-00000 per reducer, plus an empty _SUCCESS marker.
What is a Writable?mapreduce
Hadoop's compact binary serialization interface (write / readFields). Keys additionally implement WritableComparable so they can be sorted.
What is Pig and why use it?pig
A dataflow platform: scripts in Pig Latin are compiled into MapReduce jobs, so a question takes about ten lines instead of several Java classes.
GROUP ALL vs GROUP BY?pig
ALL puts every row in one group for a global answer; BY x makes one group per value, giving a per-category answer.
When does a Pig script run?pig
Only at STORE or DUMP. Pig is lazy: the statements before that build a plan.
Why cast a field to double before ORDER?pig
Without a schema a field is a bytearray and sorts as text, so "999" would rank above "1000".
How do you copy a local file into HDFS and check it?commands
hadoop fs -copyFromLocal file.txt /dir1 (or -put), then hadoop fs -ls /dir1 and hadoop fs -cat /dir1/file.txt.
How do you get a file out of HDFS?commands
hadoop fs -copyToLocal /dir1/file.txt downloaded/ (or -get).
Difference between -rm, -rmdir and -rm -r?commands
-rm deletes a file, -rmdir only an empty directory, -rm -r a directory with everything inside.
How do you run a MapReduce job from source?commands
javac -cp "$(hadoop classpath)" -d build src/…/*.java, jar cf X.jar -C build ., then hadoop jar X.jar .
How do you run a Pig script on the cluster and see its output?commands
pig -x mapreduce -f script.pig, then hadoop fs -cat 'Output.txt/part-*'.
How do you show that a file is split into blocks?commands
hdfs fsck /powerlifting/openpowerlifting.csv -files -blocks. Ours reports 7 blocks: six of 134,217,728 bytes and one of 18,313,029.
Why did you keep sum and count instead of the average in MR2?project
Averages cannot be merged when groups differ in size; sums and counts add exactly, which also makes a combiner safe.
Why can MR3's reducer also be the combiner?project
Summing is associative and commutative, and its input and output types are both (Text, LongWritable).
Why does MR1 write in cleanup()?project
The split's maximum is only known after the last record, and emitting once per split sends 7 records instead of 4 million.
