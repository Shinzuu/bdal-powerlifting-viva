How we did itFrom an empty laptop to verified results

This is the order we actually worked in. The examiner may ask "how did you set this up?" or "what problems did you face?", so know each step.

  1. Learned the basics in the lab sessionsLab 1 was Hadoop installation and configuration. Lab 2 was HDFS commands (mkdir, put, ls, cat). Lab 3 was a MapReduce program (matrix multiplication). The project reuses exactly those skills on a real dataset.
  2. Chose a real, large datasetWe picked the OpenPowerlifting bulk CSV because it is genuinely big (4 million rows, 785 MB), free to use (public domain), and has clear numeric columns to aggregate. We downloaded the zip (about 170 MB) and unzipped the 2026-09-05 snapshot.
  3. Explored it before writing any codeWe printed the header to get the column positions (head -1 file.csv | tr ',' '\n' | cat -n), and checked with awk that every row has exactly 42 fields. It does, and no field contains a comma or a quote, so a plain split(",") is safe.
  4. Installed the softwareOpenJDK 11 (Hadoop 3.4 runs on Java 8 or 11, not 17), the Hadoop 3.4.1 and Pig 0.17.0 tarballs extracted into ~/bigdata, and an env file that sets JAVA_HOME, HADOOP_HOME, PIG_HOME and PATH.
  5. Set up passwordless SSH to localhoststart-dfs.sh and start-yarn.sh start each daemon over SSH, even on one machine, so we generated a key and added it to authorized_keys.
  6. Configured four XML filescore-site.xml, hdfs-site.xml, mapred-site.xml and yarn-site.xml (details in the Hadoop section below).
  7. Formatted the NameNode once, then started the clusterhdfs namenode -format creates an empty filesystem. Then start-dfs.sh, start-yarn.sh, mapred --daemon start historyserver, and jps to see the six daemons.
  8. Put the data into HDFShdfs dfs -mkdir -p /powerlifting and hdfs dfs -put the CSV as /powerlifting/openpowerlifting.csv. HDFS split it into 7 blocks.
  9. Wrote, compiled and ran the MapReduce jobsThree Java programs, each with a Mapper, a Reducer and a Driver. Compiled with javac -cp "$(hadoop classpath)", packed with jar cf, and run with hadoop jar.
  10. Wrote and ran the Pig scriptsFive .pig files, run with pig -x mapreduce -f script.pig. Pig turned each one into MapReduce jobs on the same cluster.
  11. Verified every numberA separate awk script computed all eight answers straight from the CSV, with no Hadoop involved. Every cluster result matched. MR3 and Pig 1 answer the same question, so they also check each other.
  12. Wrote the report, then rebuilt everything once moreThe laptop was reinstalled on 2026-09-05, so we rebuilt the cluster from scratch, downloaded the newest snapshot and re-ran all eight jobs. All numbers were re-verified. That is a good answer to "is this reproducible?"

Total vs Dots

TotalKg is the sport's headline number: the sum of the best successful squat, bench press and deadlift. Heavier lifters lift more, so the total rewards absolute strength.

Dots makes lifters of different bodyweights comparable. It scales the total by a polynomial of bodyweight:

The formula Dots = TotalKg × 500 / (a + b·W + c·W² + d·W³ + e·W⁴), where W is bodyweight in kg (clamped to 40–210 kg for men, 40–150 kg for women), with separate coefficients for men and women. We checked this against 2,000 rows of the dataset and every computed value matched the Dots column to within 0.005.

That is why the Dots top 10 is mostly women, while the total top 10 is all heavy men.

Theory 1Hadoop: HDFS and YARN

Hadoop has two main parts. HDFS stores the data. YARN runs the programs. MapReduce and Pig are programs that run on YARN and read from HDFS.

The six Java processes that jps shows, and what each one does.

HDFS in five facts

  • Blocks: files are cut into fixed-size blocks, 128 MB by default. Our 785.5 MB CSV became 7 blocks (6 full ones and a 17.5 MB remainder).
  • NameNode keeps only metadata in memory: the directory tree and which blocks make up each file. It never stores the data itself.
  • DataNode stores the blocks on local disk and reports to the NameNode with heartbeats.
  • Replication: normally 3 copies of each block. We set dfs.replication to 1 because a single machine has only one DataNode.
  • Write once, read many: HDFS is built for large sequential reads, which is exactly what a MapReduce scan needs.
Trap: SecondaryNameNodeIt is not a standby or backup NameNode. It periodically merges the NameNode's edit log into a new fsimage (a checkpoint), so restarts are faster and the edit log does not grow forever.

YARN in four facts

  • ResourceManager: one per cluster. Accepts job submissions and decides where containers run.
  • NodeManager: one per machine. Launches containers (JVMs) that run the map and reduce tasks.
  • ApplicationMaster: started for each job inside a container. It asks the ResourceManager for containers and tracks the job's tasks.
  • Container: a slice of memory and CPU on a node. Each map or reduce task runs in one.

Theory 2How a MapReduce job runs

MapReduce splits a job into two functions you write, map and reduce. Hadoop does everything in between: splitting the input, running tasks in parallel, and moving and sorting the intermediate data.

Data flow of every job on this page. The shuffle moves data between tasks, so the less the mappers send, the faster the job.
StageWhat happensIn our jobs
Input splitThe input file is divided into splits, normally one per HDFS block.7 splits, so 7 map tasks
RecordReaderTextInputFormat turns a split into records: key = byte offset (LongWritable), value = the line (Text). A line that crosses a block boundary is still read whole.every mapper receives (LongWritable, Text)
MapYour map() is called once per record and may emit any number of (key, value) pairs.we split the CSV line and emit one pair (or nothing)
CombinerAn optional mini-reduce on each map task's output, before the shuffle. Hadoop may run it zero, one or many times.MR2 and MR3 use one
PartitionDecides which reducer gets each key. Default HashPartitioner: hash(key) mod number of reducers.1 reducer, so everything goes to it
Shuffle + sortMap output is copied to reducers and sorted by key, and values with the same key are grouped.why MR3's output is alphabetical by federation
ReduceYour reduce(key, values) is called once per distinct key.sum, merge, or pick the maximum
OutputEach reducer writes one file, part-r-00000, part-r-00001, …, plus an empty _SUCCESS marker.one part-r-00000 per job

Key ideas the examiner likes

  • Writable: Hadoop's own compact binary serialization. Keys and values must implement it (Text, LongWritable, IntWritable, or your own class). Keys also need to be comparable (WritableComparable) so they can be sorted.
  • Data locality: YARN tries to run a map task on the node that holds its block, moving code to the data instead of data to the code.
  • When a combiner is allowed: the operation must be associative and commutative (sum, count, min, max), and its input and output types must both equal the map output types. Average is not allowed directly.
  • Output directory: it must not exist before the job starts, so a finished result can never be overwritten by accident.
  • Driver: the main() that builds a Job: which jar, mapper, combiner, reducer, output types, input and output paths, then waitForCompletion(true).

Theory 3Apache Pig

Pig is a high-level platform on top of Hadoop. You write a script in Pig Latin, a dataflow language where each line transforms a dataset, and Pig compiles the script into MapReduce jobs for you.

What happens when you run pig -x mapreduce -f script.pig.
TermMeaning
Relationa named dataset, like raw or clean. Each statement creates a new relation.
Tupleone record: an ordered list of fields, like a row
Baga collection of tuples. After GROUP, each group holds a bag of its rows.
Fieldone value in a tuple. Without a schema, fields are named by position: $0, $1, …
Schemafield names and types. Declared with AS (name:type, …) or by casting in FOREACH.
Lazy evaluationnothing runs while statements are defined. Only STORE or DUMP triggers execution.

Handy Grunt shell commands

  • DUMP rel; runs the script up to rel and prints the result on screen.
  • DESCRIBE rel; prints the schema of a relation.
  • EXPLAIN rel; prints the logical, physical and MapReduce plans.
  • ILLUSTRATE rel; shows a small sample of data flowing through each step.
MapReduce vs Pig in one sentenceMapReduce gives full control (we chose the combiner and wrote a custom Writable) but needs a lot of Java. Pig needs about ten lines per question and writes the map and reduce steps itself, at the cost of some control.

What is the difference between hadoop fs and hdfs dfs?lab 2
For HDFS they do the same thing. hadoop fs is the generic filesystem shell that can work with any Hadoop filesystem; hdfs dfs is specific to HDFS.
What is the difference between put and copyFromLocal?lab 2
Both copy a local file into HDFS. copyFromLocal only accepts a local source; put can also read from standard input. For the lab they behave the same.
What is the difference between get and copyToLocal?lab 2
Both copy a file from HDFS to the local disk; copyToLocal is restricted to a local destination. In practice they are the same.
rmdir vs rm -r?lab 2
hadoop fs -rmdir removes only an empty directory and fails with "Directory is not empty" otherwise. hadoop fs -rm -r deletes a directory and everything inside it.
How do you create nested directories in one command?lab 2
hadoop fs -mkdir -p /dir1/x/y. Without -p it fails with "No such file or directory" when a parent is missing.
How do you overwrite a file that already exists in HDFS?lab 2
hadoop fs -put -f localfile /path. Without -f, copyFromLocal and put fail with "File exists".
In hadoop fs -ls output, what is the number after the permissions?lab 2
The replication factor of the file (1 on our cluster). Directories show a dash because they have no blocks.
How can you see how a file is stored in blocks?lab 2
hdfs fsck -files -blocks. For our CSV it shows 823619397 bytes, replication=1, 7 blocks: six of 134217728 bytes and one of 18313029.
Where does hadoop fs -ls with no path look?lab 2
In your HDFS home directory, /user/, which is /user/shinzuu here.
How do you check HDFS from a browser?lab 2
NameNode web UI at http://localhost:9870, then Utilities → Browse the file system.
What does the NativeCodeLoader warning mean?lab 2
Hadoop could not load its optional native (C) libraries and is using the built-in Java versions. It is harmless.
What dataset did you use and where is it from?dataset
The OpenPowerlifting archive, a volunteer-maintained record of powerlifting competition results worldwide, downloaded as one bulk CSV from openpowerlifting.org. Snapshot dated 2026-09-05.
How big is it?dataset
785.5 MB (823,619,397 bytes), 4,030,219 data rows plus a header, 42 columns. About 170 MB as a zip.
What does one row represent?dataset
One lifter's result at one competition. A lifter who competed many times has many rows.
Is it legal to use?dataset
Yes. The data is public domain: OpenPowerlifting waives copyright and only asks for attribution.
Which columns did you use, and at which indexes?dataset
Name $0, Sex $1, Equipment $3, TotalKg $25, Dots $27, Federation $34, Date $36. Indexes are 0-based.
What is TotalKg?dataset
The sum of a lifter's best successful squat, bench press and deadlift, in kilograms.
What is Dots and why does it exist?dataset
A bodyweight-adjusted score: total × 500 divided by a 4th-degree polynomial of bodyweight, with separate coefficients for men and women. It lets lifters of different sizes be compared, which is why its top 10 is mostly women.
How did you handle missing or bad values?dataset
Rows with an empty value in the column a job needs are skipped (270,254 empty TotalKg, 296,478 empty Dots). The header row is skipped, and in Java a non-numeric value is caught and skipped. We did not remove unusual but valid-looking values like a 1 kg total.
Did you need a CSV parser for quoted fields?dataset
No. We checked with awk that every row has exactly 42 comma-separated fields and no field contains a quote, so a plain split on commas is correct.
Why are Texas high-school federations on top?dataset
THSPA and THSWPA run very frequent, large high-school meets and record every entry, so by entry count they beat every national federation.
What are the equipment categories?dataset
Raw, Wraps, Single-ply, Multi-ply, Unlimited and Straps. Raw is the largest; Multi-ply holds the all-time total record.
What is Hadoop?hadoop
An open-source framework for storing and processing very large datasets across a cluster of ordinary machines. Its core is HDFS for storage and YARN for running jobs, with MapReduce as the processing model.
What mode did you run Hadoop in?hadoop
Pseudo-distributed: all six daemons run on one machine as separate Java processes, talking over localhost.
Name the six daemons and what each does.hadoop
NameNode (HDFS metadata), DataNode (stores blocks), SecondaryNameNode (checkpoints metadata), ResourceManager (schedules the cluster's resources), NodeManager (runs task containers on a node), JobHistoryServer (keeps finished-job history).
What is a block, and how many does your file have?hadoop
HDFS stores files as fixed-size blocks, 128 MB by default. Our 785.5 MB file has 7 blocks, which is why each job has 7 map tasks.
What is the replication factor and why is yours 1?hadoop
The number of copies of each block, normally 3. We have one DataNode, so only one copy is possible; we set dfs.replication to 1.
Is the SecondaryNameNode a backup?hadoop
No. It merges the edit log into the fsimage (checkpointing). It cannot take over if the NameNode fails.
What does the NameNode store?hadoop
Only metadata: the directory tree, file-to-block mapping and block locations. The data itself is on DataNodes.
What is safe mode?hadoop
A read-only state at NameNode startup while it waits for DataNodes to report their blocks. Writes and jobs fail until it ends; hdfs dfsadmin -safemode wait blocks until then.
Why does Hadoop need SSH on a single machine?hadoop
The start scripts (start-dfs.sh, start-yarn.sh) launch each daemon over SSH, even when the host is localhost, so passwordless SSH is required.
What is in your four config files?hadoop
core-site: fs.defaultFS hdfs://localhost:9000. hdfs-site: replication 1, NameNode and DataNode directories, SecondaryNameNode on localhost:9868. mapred-site: mapreduce.framework.name = yarn. yarn-site: aux-services = mapreduce_shuffle.
What are the YARN components?hadoop
ResourceManager (one per cluster), NodeManager (one per node), a per-job ApplicationMaster, and containers where tasks run.
Which Java version and why?hadoop
OpenJDK 11. Hadoop 3.4.x supports Java 8 and 11 at runtime; newer versions do not work.
Why do you format the NameNode only once?hadoop
Formatting creates a new, empty filesystem. Doing it again wipes all metadata, so the data already in HDFS is lost.
Explain MapReduce in simple terms.mapreduce
Map processes each input record independently and emits key-value pairs. Hadoop shuffles and sorts them so all values for one key are together. Reduce then processes each key's list of values to produce the result.
What is the shuffle?mapreduce
The phase that copies map output to reducers, partitions it by key, sorts it and groups values with the same key. It moves data over the network, so it is usually the most expensive step.
What is a combiner and when can you use one?mapreduce
A mini reducer that runs on each map task's output before the shuffle to shrink it. The operation must be associative and commutative, and its input and output types must equal the map output types. Hadoop may run it zero or more times.
What is a partitioner?mapreduce
It decides which reducer receives each key. The default HashPartitioner uses hash(key) mod number of reducers.
What is a Writable?mapreduce
Hadoop's interface for compact binary serialization, with write() and readFields(). All keys and values must be Writable; keys must also be comparable for sorting.
What does the mapper receive as input?mapreduce
With TextInputFormat, the key is the byte offset of the line (LongWritable) and the value is the line (Text).
What files does a job produce?mapreduce
One part-r-NNNNN file per reducer (we have one: part-r-00000) and an empty _SUCCESS marker.
Why must the output directory not exist?mapreduce
Hadoop refuses to overwrite it, which protects earlier results. We delete it with hdfs dfs -rm -r before re-running.
What is data locality?mapreduce
Running a map task on the node that stores its block, so code moves to the data instead of data moving across the network.
Walk me through MR1.code
Each mapper keeps the highest total it has seen in an instance field, emits nothing in map(), and in cleanup() writes its single best row under key "TOP". The one reducer receives 7 candidates and picks the maximum: Dave Hoff, 1407.5 kg.
Why does MR1 write in cleanup() instead of map()?code
cleanup() runs once after the whole split is processed, so only then is the split's maximum known. Writing in map() would emit every row.
Why does MR1 use the key "TOP" and one reducer?code
A constant key puts all candidates in one reduce group, and setNumReduceTasks(1) guarantees one reducer, so there is exactly one global answer and one output file.
Why is there no combiner in MR1?code
The mapper already reduces each split to one record (in-mapper combining), so a combiner would have nothing left to shrink.
What does split(",", -1) do?code
Splits the line on commas and keeps trailing empty strings, so a row whose last columns are empty still produces 42 fields.
Walk me through MR2.code
The mapper emits (equipment, tuple with min = max = sum = total, count = 1). A combiner merges tuples per key inside each map task. The reducer merges all of them and prints min, max, count and average = sum / count.
Why a custom Writable in MR2?code
The value must carry four numbers through the shuffle. A Writable class serializes them compactly and gives us a typed merge() method.
Why store sum and count instead of the average?code
Averages cannot be merged: the average of averages is wrong when groups differ in size. Sums and counts add up exactly, and the average is computed once at the end.
Why does MR2 need a separate Combiner class?code
Its reducer outputs Text, but a combiner must output the map output type (the tuple). So the reducer cannot double as the combiner.
Why must write() and readFields() use the same order?code
They are the two halves of one binary format. If the order differs, fields are read into the wrong variables.
Why copy the first value in the combiner instead of keeping it?code
Hadoop reuses the same object for each value in the iterator, so a stored reference would be overwritten by the next value.
Walk me through MR3.code
Word count on column 34: the mapper emits (federation, 1), and the reducer sums. The reducer class is also registered as the combiner.
Why can MR3's reducer be the combiner?code
Summing is associative and commutative, and the reducer's input and output types are both (Text, LongWritable), the map output types.
Why is MR3's output alphabetical?code
The shuffle sorts by key, so the reducer sees federations in alphabetical order. We sort by count afterwards with sort -k2 -nr.
What happens to a row where TotalKg is not a number?code
Double.parseDouble throws NumberFormatException, which we catch and ignore, so the row is skipped and the job continues.
How do you compile and package a job?code
javac -cp "$(hadoop classpath)" -d build src/pl/toptotal/*.java, then jar cf TopTotal.jar -C build ., then hadoop jar TopTotal.jar pl.toptotal.TopTotalDriver .
What is Pig and why use it?pig
A high-level dataflow platform on Hadoop. Scripts in Pig Latin are compiled into MapReduce jobs, so questions that need many Java classes take about ten lines.
Explain the first three lines of your Pig scripts.pig
LOAD reads the CSV from HDFS with PigStorage(','), giving positional fields $0…$41. FILTER drops the header and empty values. FOREACH … GENERATE keeps only the needed columns and casts them to proper types.
What is the difference between GROUP ALL and GROUP BY?pig
GROUP ALL puts every tuple into one group, for a global result. GROUP BY x makes one group per value of x, for per-category results. That one change turns Pig 2 into Pig 3.
What does FLATTEN do?pig
It un-nests a bag, turning a bag of 10 tuples into 10 separate output tuples.
Why cast $25 to double?pig
Without a schema the field is a bytearray, and sorting it as text would put 999 above 1000. As a double, the sort is numeric.
Why is ORDER inside a nested FOREACH?pig
A top-level ORDER BY failed with Pig 0.17 on Hadoop 3 in our setup, and a nested ORDER plus LIMIT is the standard way to write top-N per group anyway.
Where does STORE write the output?pig
A relative path goes into the HDFS home directory, e.g. /user/shinzuu/Top10Dots.txt/part-r-00000.
When does a Pig script actually run?pig
Pig is lazy: statements only build a plan. STORE or DUMP triggers compilation into MapReduce jobs and execution.
Why did top5Federations become two jobs?pig
It groups twice (by federation to count, then ALL to rank), and Pig compiled it into two MapReduce jobs. So YARN shows 9 applications for 8 analyses.
What are local mode and MapReduce mode?pig
pig -x local runs in one JVM on local files, good for testing. pig -x mapreduce runs real MapReduce jobs on YARN over HDFS, which is what we used.
What do DUMP, DESCRIBE, EXPLAIN and ILLUSTRATE do?pig
DUMP prints a relation's data, DESCRIBE its schema, EXPLAIN its execution plans, and ILLUSTRATE a small sample through each step.
How do you know your results are correct?results
An awk script recomputed all eight answers directly from the CSV without Hadoop, and every value matched. MR3 and Pig 1 also agree with each other, and in the demo each output is diffed against the saved result.
What were your main findings?results
Highest total 1407.5 kg by Dave Hoff (Multi-ply). Highest Dots 818.06 by Deana Tollefson. THSPA is the busiest federation with 535,620 entries. Wraps has the highest average total (513.71 kg) and Raw the most entries (1,845,444 with a total).
How long did the jobs take?results
About 35–40 seconds per MapReduce job and about 1 minute per Pig script on our laptop, with 7 map tasks each.
How would you find the average Dots per sex in MapReduce?what if
Mapper: key = f[1] (sex), value = (sum = Dots, count = 1) using a Writable like MinMaxCountAvgTuple, skipping empty f[27]. Combiner merges sums and counts; reducer outputs sum / count.
How would you count entries per country in Pig?what if
LOAD, FILTER BY $37 != '', FOREACH GENERATE (chararray)$37 AS country, GROUP BY country, FOREACH GENERATE group, COUNT(...), STORE.
What would change with 3 reducers in MR3?what if
Keys would be hash-partitioned across three reducers, producing part-r-00000 to part-r-00002, each sorted by key on its own. The totals would be the same.
What if you set 3 reducers in MR1?what if
All records still share key "TOP", so one reducer gets all 7 and the other two write empty files. That is why the driver fixes it at 1.
How would this scale to a real cluster?what if
The code does not change. More DataNodes store the blocks with replication 3, and more NodeManagers run the 7 map tasks in parallel on different machines, close to their data.
